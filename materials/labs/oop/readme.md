# OOP - Hands-on Lab

1. Create an object called `Book` that has `title` and `author` attributes

2. Create an object called `Library` that has an attribute called `catalogue` which can store **multiple books**. This class also has some methods that consist of:
   - method `addBook`
     - This method will have **1 parameter** to **store** the Book object into `catalogue`
   - method `removeBook`
     - This method will have **1 parameter** to **remove** Book from `catalogue` based on its `title`
   - method `showBooks`
     - This method will **show** all Books from `catalogue`
